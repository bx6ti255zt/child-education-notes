# 3月后,您需要预防这些病……

> 更新时间：2026-09-16 (UTC+8)

春季预防

进入3月，万物复苏，春天悄悄地来了。春季雨水增多，也成为了病毒、病菌滋生的“温床”。我们除了需要重点预防新冠肺炎外,还需警惕诺如病毒感染性腹泻、登革热等急性传染病。 

登革热，你了解多少？

**什么是登革热？**

登革热是由登革热病毒引起，经伊蚊叮咬传播的一种以发热、皮疹和全身疼痛为主要症状的急性传染病，通常在夏秋季节高发。

**怎么传播？**

传播登革热病毒的罪魁祸首是白纹伊蚊，被带有病毒的白纹伊蚊叮咬后有可能得病。伊蚊有两个显著的习性：

白天吸血：雌蚊喜吸人血，吸血高峰在日落前2小时（约为下午5、6时）和早上8、9时，室内和室外皆可叮咬人。

室内的瓶罐、花瓶、厨房及浴室的积水、室外的坑洼、树洞、竹筒等积水处，均是蚊虫孳生的温床。

**登革热的症状**

登革热的潜伏期是3-14天，即在蚊子叮咬后3-14天内发病。主要症状有：突发高热，体温可达39℃；三痛：主要为剧烈头痛、眼眶痛、关节肌肉痛；皮肤可有皮疹及恶心、呕吐等消化道症状。

**什么情况下怀疑自己得了登革热？**

发病前14天内到过有登革热流行的国家或地区；

发病前14天内有可疑蚊子叮咬史；

出现上述登革热样症状。

诺如病毒你了解多少？

**什么是诺如病毒感染？**

诺如病毒感染是由诺如病毒引起的胃肠道传染病，发病急、传播速度快、涉及范围广，主要症状为恶心、呕吐或腹痛、腹泻。

**如何传播？**

可通过食物、水、接触等多种方式传播。

**如何预防？**

1. 勤洗手、常通风、保持个人卫生。

2. 饮食饮水要卫生，食物充分加热，定期对餐具进行消毒，在外就餐不吃生冷、半生的海产品和水产品等食物。

3. 如有人员发生呕吐时，应佩戴手套和口罩规范处理呕吐物，对污染的表面用含氯消毒剂进行消毒。

4. 诺如病毒感染性腹泻容易在托幼机构、学校、养老院等集体单位传播扩散。托幼机构、学校、养老院等集体单位要落实健康监测制度；发现呕吐、腹泻等急性胃肠炎病例异常增多时，立即向当地卫生部门和市场监督管理部门报告，并配合开展调查和落实各项防控措施，控制疫情扩散。
